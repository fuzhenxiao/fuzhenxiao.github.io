Recent Projects

QASM-Eval

QASM-Eval is a dataset for training and evaluating LLMs on OpenQASM 3 beyond quantum circuits. Rather than concentrating on quantum-algorithm design, it targets the hardware-facing language features needed for NISQ workflows: classical logic, timing and scheduling, pulse control, and complex real-world programming tasks. The release includes 4,000 training tasks and an expert-verified 100-task test set, along with an extended verifier for syntax, quantum-state, and program-timeline correctness.

QAgent

QAgent is a multi-agent framework for autonomous OpenQASM programming. It combines schema-aware planning and correction, task routing between guided few-shot and tools-augmented coding agents, retrieval-augmented generation, and automatic quantum-hardware calibration. Its collaborative workflow turns high-level requests into OpenQASM programs and structured reports, with iterative simulation, testing, review, and refinement to improve code correctness.
