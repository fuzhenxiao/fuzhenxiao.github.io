QASM-Eval

QASM-Eval is a dataset for training and evaluating LLMs on OpenQASM 3 beyond quantum circuits. It focuses on hardware-facing programming capabilities, including classical logic, timing scheduling, pulse control, and complex real-world workflows. The project provides an expert-verified test set of 100 tasks, a training set of 4,000 tasks, and an extended verifier that checks syntax, quantum states, and program timelines.
